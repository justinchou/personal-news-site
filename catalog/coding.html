AI 编程与 Agent 发展脉络

七个阶段不是严格替代关系。当前最前沿被概括为 Agentic Software Engineering（智能体驱动的软件工程）。

七个发展阶段

点击或用 ← → 切换阶段
1

第 1 阶段 · Code Completion

代码补全

成熟

程序员写代码，AI 预测下一行或下一段代码。

人机分工人负责绝大部分工作，AI 负责提高编码速度。

AI 的角色代码助手
⇄
人的角色程序员

  • GitHub Copilot ↗github.com
  • Tabnine
  • Codeium

关键技术

代码上下文理解语言模型Fill-in-the-Middle

第 2 阶段 · Chat-based Coding

编辑器内 AI Chat

成熟

开发者选中代码、提出问题，AI 解释、修改和生成代码。

人机分工AI 开始理解多个文件，但仍主要由人控制任务。

代表产品

  • GitHub Copilot Chat
  • Codeium Chat
  • Amazon Q Developer

关键技术

代码上下文RAG代码库检索

第 3 阶段 · AI Native IDE

AI 原生独立编辑器

成熟

AI 深度融入整个 IDE，理解代码库，可以同时修改多个文件。

人机分工AI 不再只是代码输入助手，而是参与整个开发流程。

AI 的角色编程搭档
⇄
人的角色主导开发

人机分工AI 开始模拟一个软件开发团队。

第 7 阶段

Agent Bot / 自主软件工程系统

早期

通过自然语言、Issue、Webhook、定时任务或业务事件触发开发任务。

人机分工AI 不再等待程序员打开 IDE，而是能够在开发工作流中主动接收和执行任务。

AI 的角色自动化开发服务
⇄
人的角色产品负责人

代表产品

  • Slack Bot
  • GitHub Bot
  • 企业内部开发 Bot
  • 长期运行的编码 Agent

关键技术

Agent Runtime持久化任务状态事件驱动工具权限可观测性

成熟度来自整理对话中的主观判断，不是官方统计：1–4 成熟，5 商用，6 发展中，7 早期。对话认为 2026 年处于第 5 阶段向第 6 阶段过渡。

人机角色演进

AI 从助手变成团队，人从写代码变成定目标
  1. Code Completion代码助手人：程序员
  2. AI IDE编程搭档人：主导开发
  3. Coding Agent软件开发执行者人：任务分配者
  4. Cloud Agent云端开发工程师人：监督者
  5. Multi-AgentAI 开发团队人：技术负责人
  6. Coding Bot自动化开发服务人：产品负责人
  7. Software Factory自主软件生产系统人：目标制定与治理者

核心判断

最看好的方向不是再做一个 AI IDE，而是做一个能够连接多个 Coding Agent、管理多个项目、自动执行开发任务、验证代码并完成交付的 AI 软件工程平台。

护城河：Agent Harness软件工程执行环境任务验证能力

当前前沿方向

方向 1

多 Agent 并行开发

Orchestrator、Frontend、Backend、QA、Security、Integration & Release 等 Agent 分工。

  • Multi-Agent Orchestration
  • Task Dependency Graph
  • Git Worktree 隔离
  • 并行任务调度
  • 代码冲突解决
  • 统一测试与集成

方向 2

长时间自主执行（Long-running Agent）

  • 接受一个复杂目标
  • 持续工作几十分钟甚至更长
  • 保存任务状态
  • 遇到错误自动调整
  • 必要时请求人类批准
  • 最终交付可验证的结果

方向 3

Computer Use Agent

  • 打开浏览器
  • 操作网页
  • 使用图形化软件
  • 点击按钮
  • 填写表单
  • 查看执行结果
  • 根据屏幕反馈继续操作

方向 4

Agent Skills + MCP

未来竞争力不只是模型有多聪明，还包括围绕模型构建的 Harness 是否优秀。

  • MCP：如何连接外部工具，连接 GitHub、数据库、浏览器等
  • Skills：如何掌握专业工作流程，提供规则、知识、脚本和方法
  • AGENTS.md：如何理解项目规范，项目级开发约束和说明
  • Agent SDK：如何把 Agent 嵌入应用，开发自己的 Agent 产品
  • Harness：如何稳定运行 Agent，管理上下文、执行、权限、恢复

方向 5

事件驱动的 Coding Bot

  • Slack：用户直接通过聊天指挥开发 Agent。
  • Discord：团队开发 Bot。
  • Telegram：个人 AI 开发助手。
  • GitHub：Issue、PR 自动触发开发。
  • Web Dashboard：统一管理所有 Agent。
  • 企业内部系统：通过 API 接入业务流程。

方向 6

Software Factory（AI 软件工厂）

  • Human / Product Owner
  • Product Agent
  • Architecture Agent
  • Design Agent
  • Coding Agents
  • QA Agents
  • DevOps Agent
  • Software Delivery Platform

未来三年判断

  1. 第一阶段：2026

    Agent 成为主要开发工具

    • IDE 和 Terminal Agent 融合。
    • 多 Agent 并行。
    • 云端开发任务。
    • 人类从写代码转向审查和管理。
  2. 第二阶段：2027

    软件开发流程自动化

    • Issue 自动转化为开发任务。
    • 自动修复 Bug。
    • 自动测试和 PR。
    • Agent 之间协作和交接。
  3. 第三阶段：2028

    自主软件工程平台

    • 持续理解整个软件系统。
    • 主动发现技术债和异常。
    • 根据业务需求持续迭代。
    • 人类主要负责产品方向、架构约束和关键审批。
