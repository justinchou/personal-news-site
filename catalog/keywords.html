基础概念

19 个

AI（Artificial Intelligence）

人工智能

让机器完成感知、推理、生成与决策等通常需要人类智能的任务。

AGI

通用人工智能

在几乎所有认知任务上达到或超过人类水平的通用 AI，目前没有统一判定标准。

LLM

大语言模型

在海量文本上训练、按 Token 预测下一个词的大型神经网络，是当今对话 AI 的底座。

Generative AI

生成式 AI

能生成文本、图像、音频、视频、代码等新内容的 AI，而不只是分类或预测。

Foundation Model

基础模型

用大规模通用数据预训练、可适配大量下游任务的大模型，如 GPT、Claude、Qwen。

Multimodal AI

多模态 AI

在一个模型里同时理解和生成文本、图像、音频、视频等多种模态。

Deep Learning

深度学习

用多层神经网络从数据中自动学习特征的机器学习方法，现代 AI 的技术主干。

Transformer

Transformer 架构

2017 年提出的注意力机制架构，几乎所有主流大模型都基于它。

Neural Network

神经网络

由大量带权重的“神经元”层层连接组成的计算模型，通过训练调整权重。

Inference

模型推理

训练好的模型接收输入、产出结果的过程；用户每次提问都在消耗推理算力。

Token新增

词元

模型处理文本的最小单位，约等于半个到一个汉字；计费、上下文长度都按它算。

Context Window新增

上下文窗口

模型一次能“看到”的最大 Token 数，从几千涨到百万级，决定能塞多少资料。

Scaling Law新增

规模定律

模型能力随参数、数据、算力按幂律稳定提升的经验规律，驱动了算力军备竞赛。

Frontier Model新增

前沿模型

能力处于业界最前沿的少数旗舰模型，也是监管与安全讨论的重点对象。

ASI新增

超级人工智能

在几乎所有领域显著超越最强人类的 AI，是 AGI 之后更远的设想。

Prompt Engineering新增

提示词工程

通过设计指令、示例和格式来引导模型输出，是使用大模型的基本功。

Chain-of-Thought新增

思维链

让模型先写出中间推理步骤再给答案，显著提升复杂问题准确率。

Diffusion Model新增

扩散模型

从噪声逐步去噪生成图像或视频的模型，Stable Diffusion、Sora 类产品的基础。

VLM新增

视觉语言模型

能同时看图和读文字的模型，是多模态理解、Computer Use 的基础。

模型与训练

16 个

Pre-training

预训练

在海量无标注数据上做自监督学习，让模型获得语言与世界的通用知识。

Fine-tuning

微调

在预训练模型基础上用少量特定数据继续训练，让它适应某个任务或风格。

SFT

监督微调

用人工编写的“问题-理想回答”对来微调模型，教它按指令作答。

RLHF

人类反馈强化学习

让人给模型的多个回答排序，训练奖励模型，再用强化学习让模型更符合人类偏好。

DPO

直接偏好优化

直接用偏好数据优化模型、无需单独奖励模型的对齐方法，比 RLHF 更简单稳定。

Reasoning Model

推理模型

回答前先进行较长“思考”（思维链）的模型，如 o 系列、DeepSeek-R1，擅长数学与代码。

Test-time Compute

测试时计算

推理阶段投入更多计算（多想几步、多次采样）来换取更好答案，与训练算力相对。

MoE

混合专家模型

模型由多个“专家”子网络组成，每个 Token 只激活其中少数，参数大但推理便宜。

Quantization

模型量化

把模型权重从 16 位压到 8/4 位等更低精度，显著降低显存与推理成本。

Distillation

模型蒸馏

用大模型（老师）的输出训练小模型（学生），让小模型以低成本逼近大模型能力。

LoRA新增

低秩适配

只训练少量附加参数就能微调大模型的方法，成本低，开源社区最常用。

RLVR新增

可验证奖励强化学习

用可自动判对错的任务（数学、代码测试）作为奖励来强化训练，推理模型的关键配方。

GRPO新增

组相对策略优化

DeepSeek 提出的强化学习算法，组内比较多个回答打分，省去价值模型、训练更省。

Reward Model新增

奖励模型

给模型回答打分的模型，RLHF 中用来代表人类偏好。

Open Weights新增

开放权重

公开模型权重供下载部署，但不一定公开训练数据和代码，区别于严格开源。

SLM新增

小语言模型

参数在几十亿以内、可在手机或单卡运行的模型，主打低成本和隐私。

算力与基础设施

16 个

GPU

图形处理器

擅长大规模并行计算的芯片，NVIDIA GPU 是当前 AI 训练和推理的主力算力。

TPU

张量处理器

Google 自研的 AI 专用芯片，用于训练和服务 Gemini 等模型。

NPU

神经网络处理器

手机、PC 等终端里的 AI 加速单元，用于本地低功耗运行模型。

CUDA

NVIDIA 并行计算平台

NVIDIA 的 GPU 编程平台和软件生态，是其最深的护城河之一。

HBM

高带宽内存

堆叠在芯片旁的高带宽显存，决定大模型能装多大、跑多快，产能紧缺。

Training Cluster

训练集群

由成千上万张 GPU 通过高速网络互联组成的训练系统，规模即竞争力。

Inference Engine

推理引擎

专门优化模型推理速度与吞吐的软件，如 vLLM、TensorRT-LLM、SGLang。

vLLM

大模型推理框架

开源高性能 LLM 推理框架，以 PagedAttention 提升显存利用率，部署事实标准之一。

KV Cache

键值缓存

缓存已计算过的注意力键值，避免生成每个新 Token 时重复计算，长上下文的关键。

Tokens per Second

每秒 Token 数

每秒生成的 Token 数，衡量模型输出速度和用户体感的核心指标。

ASIC新增

专用集成电路

为特定计算定制的芯片，如 TPU、Trainium，用来摆脱对通用 GPU 的依赖。

Interconnect新增

高速互联

NVLink、InfiniBand 等连接成千上万张 GPU 的网络，集群规模的瓶颈所在。

Speculative Decoding新增

推测解码

小模型先快速草拟多个 Token、大模型一次性验证，在不降质量下加速生成。

TTFT新增

首 Token 延迟

从发出请求到收到第一个 Token 的时间，决定交互是否“跟手”。

On-device AI新增

端侧 AI

在手机、PC、汽车本地运行模型，无需联网，延迟低且更隐私。

AI Data Center新增

AI 数据中心

为 AI 训练推理专建的超大规模机房，电力与散热已成为最大约束。

Agent 智能体

20 个

AI Agent

AI 智能体

能理解目标、自主规划并调用工具完成多步任务的 AI 系统。

Agentic AI

智能体式 AI

强调自主行动与多步执行的 AI 形态，从“回答问题”走向“完成任务”。

Agent Loop

Agent 执行循环

Agent 的核心循环：思考 → 调用工具 → 观察结果 → 再思考，直到完成目标。

Tool Calling

工具调用

模型输出结构化调用指令，由程序去执行搜索、读写文件、调 API 等操作。

Function Calling

函数调用

Tool Calling 的早期叫法：模型按 JSON Schema 输出要调用的函数和参数。

Planning

任务规划

把复杂目标拆成可执行的子步骤并安排顺序，是 Agent 可靠性的关键能力。

Memory

记忆系统

让 Agent 跨轮次、跨会话记住事实与偏好，分短期上下文与长期存储。

Context Engineering

上下文工程

系统化地决定给模型看什么信息、以什么格式，比写提示词更进一步。

RAG

检索增强生成

先从外部知识库检索相关资料再交给模型生成，减少幻觉、接入私有知识。

MCP

模型上下文协议

Anthropic 提出的开放协议，统一 AI 应用连接外部工具和数据的方式，被称为 AI 的 USB-C。

Skills

Agent 技能

打包好的说明、脚本与资源，让 Agent 按需加载某类专业工作流程。

Multi-Agent

多智能体

多个分工不同的 Agent 协作完成任务，如规划者、执行者、审查者。

Orchestration

编排调度

调度多个模型、工具或 Agent 的执行顺序、并发与状态流转。

Agent Runtime

Agent 运行环境

承载 Agent 运行的环境：沙箱、工具权限、状态持久化、日志与恢复。

Harness Engineering

Agent 执行框架工程

围绕模型搭建的执行框架（提示、工具、反馈、重试），决定 Agent 实际表现。

A2A新增

Agent 间协议

Google 牵头的开放协议，让不同厂商的 Agent 能互相发现、委托任务和通信。

Vibe Coding新增

氛围编程

用自然语言描述需求、让 AI 写出大部分代码，开发者主要看效果而非逐行审代码。

Spec-driven Development新增

规格驱动开发

先写清需求规格和验收标准，再让 Agent 按规格实现与自测。

Sandbox新增

沙箱

与主机隔离的执行环境，让 Agent 安全地运行代码、安装依赖。

Deep Research新增

深度研究

Agent 自主多轮搜索、阅读、汇总，几分钟内产出带引用的研究报告。

数据与知识

10 个

Dataset

数据集

用于训练或评测模型的数据集合，质量与规模直接决定模型上限。

Synthetic Data

合成数据

由模型生成的训练数据，用来弥补真实数据不足，已是前沿训练标配。

Data Labeling

数据标注

人工或半自动地为数据打标签、写答案、排序偏好，供监督训练使用。

Embedding

向量嵌入

把文本、图片等映射成向量，语义相近的内容在向量空间里距离更近。

Vector Database

向量数据库

专门存储和快速检索向量的数据库，RAG 系统的常见底座。

Semantic Search

语义搜索

按意思而非关键词匹配来检索内容，基于 Embedding 相似度。

Knowledge Graph

知识图谱

用“实体-关系-实体”结构组织知识，便于推理和关联查询。

Chunking

文本分块

把长文档切成适合检索的小段，切法直接影响 RAG 的召回质量。

Reranking

重排序

对初步检索结果用更精细的模型重新排序，把最相关的放到前面。

GraphRAG

图谱增强检索

结合知识图谱与 RAG，先抽取实体关系再检索，擅长跨文档的全局问题。

API 与开发平台

13 个

Model API

模型接口

通过 HTTP 接口按量调用模型，开发者无需自己部署。

API Gateway

API 网关

位于应用与多家模型 API 之间的统一入口，负责鉴权、路由、限流与计费。

Model Aggregator

模型聚合平台

一个 Key 接入多家模型的聚合平台，如 OpenRouter，方便比较与切换。

Model Router

模型路由

按任务难度、价格、延迟自动挑选最合适模型的路由层。

API Proxy

API 代理

转发模型请求的中间层，用于统一接口、跨区访问或集中管理 Key。

Fallback

故障回退

主模型失败或超时时自动切换到备用模型，保证服务可用。

Load Balancing

负载均衡

把请求分摊到多个 Key、供应商或实例上，提升吞吐与稳定性。

Rate Limiting

速率限制

限制单位时间内的请求或 Token 数，防止超额与滥用。

Observability

可观测性

记录每次模型调用的输入、输出、延迟、成本，便于排错与优化。

BYOK

自带 API Key

Bring Your Own Key：在第三方平台使用自己的模型厂商 API Key。

Structured Output新增

结构化输出

强制模型按 JSON Schema 等固定格式输出，便于程序可靠解析。

Prompt Caching新增

提示缓存

重复使用的长前缀只计算一次并打折计费，大幅降低 Agent 与长文档成本。

Realtime API新增

实时语音 API

支持低延迟语音进、语音出的流式接口，语音 Agent 的底层能力。

产品与应用

12 个

AI Copilot

AI 副驾驶

嵌入现有软件、在旁辅助用户的 AI 助手，人始终掌控主导权。

AI IDE

AI 原生编辑器

以 AI 为核心重新设计的代码编辑器，如 Cursor、Windsurf。

Coding Agent

编程智能体

能自主读代码、改多文件、跑测试、修 Bug 的编程 Agent，如 Claude Code、Codex。

Cloud Agent

云端智能体

在云端沙箱里异步运行的 Agent，完成后提交结果或 PR，可同时开多个。

Computer Use

计算机操作能力

让模型看屏幕截图并操作鼠标键盘，像人一样使用电脑软件。

Browser Agent

浏览器智能体

能自主浏览网页、点击、填表、提取信息的 Agent。

Voice Agent

语音智能体

以实时语音对话为界面的 Agent，用于客服、助理、外呼等。

AI Avatar

AI 数字人

由 AI 生成和驱动的数字人形象，可说话、做表情，用于视频与直播。

Vertical AI

垂直行业 AI

深耕某一行业（法律、医疗、金融等）的 AI 产品，靠行业数据与流程取胜。

AI SaaS

AI 软件即服务

以订阅方式交付、核心功能由 AI 驱动的软件服务。

AI Search新增

AI 搜索

直接给出综合答案并附来源的搜索方式，如 Perplexity，正在改变搜索与流量格局。

Text-to-Video新增

文生视频

用文字描述直接生成视频片段，如 Sora、Veo、可灵。

评测与安全

18 个

Benchmark

基准测试

用标准题目集衡量模型能力的评测基准，便于横向对比。

Arena Elo

人类偏好评分

让用户盲比两个模型回答并投票，按 Elo 体系计算的综合排名分。

MMLU-Pro

多学科知识评测

覆盖数十学科的高难度多选题评测，衡量知识广度与推理。

GPQA

专家级科学问题测试

研究生水平、难以搜索作答的科学问答评测，常用其 Diamond 子集。

SWE-bench

软件工程评测

用真实 GitHub Issue 测模型能否改代码并通过测试，编程 Agent 的核心指标。

Hallucination

AI 幻觉

模型自信地编造不存在的事实、引用或代码，是落地的主要风险。

Guardrails

安全护栏

在模型输入输出两侧加的规则与过滤，阻止有害、越权或格式错误的内容。

Red Teaming

红队测试

组织专人模拟攻击者寻找模型的安全漏洞与滥用方式。

Alignment

模型对齐

让模型的目标与行为符合人类意图与价值观的研究与工程。

Evals

模型评估体系

针对自身业务场景构建的评估集与流程，用来量化模型或 Agent 改进效果。

LLM-as-a-Judge新增

模型当裁判

用强模型给其他模型的输出打分，低成本扩展评测，但有偏见风险。

Prompt Injection新增

提示词注入

在网页、文件等外部内容里藏指令，诱导 Agent 执行非预期操作，Agent 安全头号威胁。

Jailbreak新增

越狱

用特殊话术绕过模型的安全限制，让它输出本应拒绝的内容。

Interpretability新增

可解释性

研究模型内部如何表征和计算，试图看懂“黑箱”，如 Anthropic 的特征可视化。

Reward Hacking新增

奖励投机

模型钻奖励规则的空子拿高分却没真正完成任务，如改测试让其通过。

Benchmark Contamination新增

评测污染

测试题混进了训练数据，导致分数虚高，削弱榜单可信度。

ARC-AGI新增

ARC-AGI 评测

考察抽象推理和少样本泛化的视觉谜题评测，被视为衡量通用智能的风向标。

Humanity's Last Exam新增

人类最后的考试

由各领域专家出题的超高难度综合评测，用来测试前沿模型的知识与推理上限。

商业与生态

12 个

AI-as-a-Service

AI 即服务

把模型能力以云服务形式出售，按调用或订阅收费。

Token Economy

Token 经济

以 Token 为计量单位的定价与成本体系，Token 用量即收入与成本。

Inference Cost

推理成本

每次调用模型所花的算力费用，决定 AI 产品毛利，正快速下降。

Unit Economics

单位经济模型

单个用户或单次任务的收入与成本结构，判断 AI 业务能否赚钱。

Vertical SaaS

垂直行业软件

面向单一行业的软件，AI 正在让这一类产品重新洗牌。

AI Native

AI 原生

从第一天就围绕 AI 能力设计的产品或公司，而非在旧产品上加 AI。

Agent OS

智能体操作系统

管理多个 Agent 的权限、记忆、工具与调度的系统层，类比操作系统。

Software Factory

软件工厂

由 Agent 流水线持续产出、测试和交付软件的模式。

Data Moat

数据护城河

独有数据带来的竞争壁垒，在模型同质化后更显重要。

AI Governance

AI 治理

围绕 AI 的法规、合规、审计与风险管理体系，如欧盟 AI 法案。

Sovereign AI新增

主权 AI

国家或地区自建算力、模型与数据体系，以掌控 AI 能力和数据主权。

Agentic Commerce新增

智能体电商

由 AI Agent 代用户比价、下单和支付的购物方式，支付与电商巨头都在布局。

World Model

世界模型

Physical AI

物理 AI

Embodied AI

具身智能

拥有身体（机器人）并通过与环境交互来学习的 AI。

Autonomous Agent

自主智能体

AGI Evaluation
