全球最值得关注的排行榜

Arena（原 Chatbot Arena / LMSYS）

人工盲测参考

用户同时向两个匿名模型提问，比较两个模型的回答，再由用户投票决定哪个更好。

  • 采用成对比较（Pairwise Comparison）。
  • 使用 Bradley-Terry 等统计方法计算模型偏好评分。
  • 按模型类别提供排行榜，例如文本、代码、图像等。
  • 更接近真实用户对模型回答质量的主观评价。

优点：不完全依赖模型厂商自己公布的测试成绩。；缺点：用户群体、问题类型和语言都会影响结果；回答更受欢迎，不一定代表事实准确率更高。

Artificial Analysis

综合能力与性价比

多项基准测试组合评分，同时测量模型实际推理服务的性能。

  • Intelligence：综合智能水平。
  • Coding：编程能力。
  • Reasoning：推理能力。
  • Speed：生成速度。
  • Price：输入、输出 Token 成本。
  • Cost per Task：完成任务的实际成本。

优点：能同时比较能力、速度和价格，非常适合企业选型和商业分析。；缺点：综合指数的权重和测试集由平台定义，不等于所有业务场景的表现。

LiveBench

客观任务测试

使用可验证答案的客观测试题，并定期更新测试数据，降低训练数据污染的风险。

  • 数学
  • 编程
  • 推理
  • 数据分析
  • 指令遵循
  • Agent 能力

优点：更重视可验证的任务结果，而不是单纯让另一个 AI 判断答案好不好。；缺点：unknown

Hugging Face Open LLM Leaderboard

开放模型评测

通过标准化学术测试集，对模型进行统一评估。

  • MMLU-Pro
  • GPQA
  • IFEval
  • 数学及知识理解测试

优点：适合研究开源模型、模型权重、微调和部署。；缺点：Open LLM Leaderboard 是 Hugging Face 的特定项目，不应将其视为所有闭源和开源模型的统一总榜。

全球 AI 模型综合评分框架（建议版）

可自行采用的评分设计，并非任何官方机构发布的统一标准。总分建议为 100 分。各维度权重未在对话中给出。

  • 能力分（Capability Score）：模型能做什么。
  • 商业分（Business Score）：使用它要花多少钱，速度如何。
  • 实用分（Practical Score）：真实任务中是否稳定、可靠。
