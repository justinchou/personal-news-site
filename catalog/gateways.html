01全球模型 API 聚合平台

6 个

一个 API Key 接入大量模型，偏开发者方便调用多家模型。

OpenRouter

官网 ↗openrouter.ai
优先比较
  • 一个 API Key 接入大量模型
  • OpenAI 兼容 API
  • 模型价格、上下文窗口、能力信息
  • Provider 路由和故障切换
  • Auto Router 自动选择模型
  • 统一充值和使用量统计

计费按模型 Token 用量计费，平台充值和 BYOK（自带 Key）有不同收费规则。

Requesty

官网 ↗requesty.ai
优先比较
  • 多模型统一 API
  • 模型路由和故障切换
  • 成本与调用监控
  • 面向开发团队的模型管理

计费API 用量和平台套餐，具体以当前计划为准。

Eden AI

官网 ↗edenai.co
  • LLM、OCR、语音、图像、翻译
  • 多家 AI 服务商统一 API
  • 多供应商比较与切换
  • 不只做语言模型

计费按 API 使用量和服务套餐。

Unify

官网 ↗unify.ai
  • 多模型 API
  • 根据质量、速度和成本进行模型选择
  • 支持模型效果比较
  • 面向应用开发者优化调用策略

计费按使用和平台服务规则。

ZenMux

官网 ↗zenmux.ai
优先比较
  • 多家模型统一 API
  • 面向 Agent 和应用的模型接入
  • 多模型路由和成本管理
  • 可作为 OpenRouter 类产品的替代方案

计费按模型调用和平台规则。

AI/ML API

官网 ↗aimlapi.com
  • 多种语言模型和生成模型
  • 统一 API 接口
  • 支持文本、图像、音频等 AI 能力
  • 面向开发者和应用平台

计费按模型和用量计费。

如何选择

个人开发者首选

OpenRouter。想快速使用 GPT、Claude、Gemini、DeepSeek 等模型，不想管理多个供应商账号。

国内模型 API

硅基流动 / 阿里云百炼。主要使用国产模型，关注国内访问、计费和服务支持。

企业级模型网关

Portkey / LiteLLM。希望统一管理 API Key、权限、预算、故障切换和日志。

自建中转服务

New API / LiteLLM。想自己部署、管理用户、渠道、额度、模型路由和账单。

开放模型高性能推理

Together AI / Fireworks / Groq。希望降低自建 GPU 维护成本，获得高性能推理服务。

自托管指网关或服务本身可以部署在自己的环境，不代表上游模型也在本地运行。表格是产品定位比较，不是功能完整性或 SLA 认证。
