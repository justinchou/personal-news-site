如何选择

  • 个人开发者首选：OpenRouter。想快速使用 GPT、Claude、Gemini、DeepSeek 等模型，不想管理多个供应商账号。
  • 国内模型 API：硅基流动 / 阿里云百炼。主要使用国产模型，关注国内访问、计费和服务支持。
  • 企业级模型网关：Portkey / LiteLLM。希望统一管理 API Key、权限、预算、故障切换和日志。
  • 自建中转服务：New API / LiteLLM。想自己部署、管理用户、渠道、额度、模型路由和账单。
  • 开放模型高性能推理：Together AI / Fireworks / Groq。希望降低自建 GPU 维护成本，获得高性能推理服务。
